On a supported non-null result, the continuation first copies attribute bit 0 for all 65,536 cells in ascending order, then scans all cells again. It reuses the existing `regioes_mapa.obstaculo_natural` predicate against live u16 tiles, object bytes and the explicit 702-byte marker table; cells without a natural obstacle are changed to class zero. This two-pass order is retained rather than collapsed into one comprehension. Success returns a new explicit handoff retaining the live class buffer/handle before component allocation. It does not label regions, insert units, correct map edges, release resources or return final remap success.

No raw ETA table or synthetic zero marker default is treated as loaded runtime data.
