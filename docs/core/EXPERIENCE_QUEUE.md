# Recruitment experience queue

Stage 7 inventory before implementation, 2026-10-28. Intact executable SHA-256 `6c556520c084b9300d9ac01900d1505126085c5f64b1ac5e5b615ea41c8543fb`; ranges are end exclusive. The original SBL symbol at `0x44f9e0` is **EnginSetNewExperience**, confirmed by the committed symbol inventory and focused REA dossier. Earlier core handoff wording called it EnginSetLevel informally. It differs from combat's requested `EnginSetLevelExperience` at `0x44fb20`; that provider remains open.

Public entries are `aplicar_nova_experiencia(mundo, indice, nivel, tipos_unidades=None)` for `0x44f9e0..0x44fb09` plus epilogue `0x44f987..0x44f98a`, `consumir_experiencia_unidade(mundo, indice, tipos_unidades=None)` for `EnginSetExperimente` `0x44fe42..0x44ff1d` plus `0x440d58..0x440d5e`, and `retomar_experiencia_saida` for the production caller `0x420f81..0x420f8a`.

All calls use the live 800 × 276-byte bytearray pool; AX index truncates to u16 then requires 0–799. Level DL truncates to u8. No activity/owner guard applies to the local level helper. Levels 0 and 5–255 return without stores; level 2 sets F6=1; level 3 sets F5=1. Level 1 sets F7=1 for types {0,1,2,3,8,11,12,15,16,18,19,20,21,22,23,24,25}; other types set F8 to low u8 of loaded u16 type `+0x2e` divided by 100. Level 4 sets F8 for all types: the same class divides the word by 100, others divide twice the word by 100. Doubling occurs in u32 before division, without a u16 wrap. The helper changes neither AF nor existing F5–F8 fields other than its single selected store.

Type data is required only at the original table read (`0x44fa71` or `0x44fafa`). Missing data raises an explicit dependency at that point. Protected malformed data or out-of-table type fails there too; paths that never read the table can use unknown type bytes. No callback or physical effect is invoked.

`mundo.experiencias_unidades` is a raw mutable 40-byte table corresponding to `0x4e19c4`, four owner records of five (type, experience) byte pairs each. The synthetic constructor initializes zero bytes, without claiming a mission-load default. The queue helper supports owners 0–3; other owners fail before mutation because the surrounding original allocation is not modeled. It reads the owner's first experience byte first: zero returns immediately, then mismatched type returns. A match stores that experience byte at unit AF, applies `AF>>5` through the local helper, shifts four following pairs left (experience then type in each iteration), clears final experience then sets final type to FF. A nested data failure leaves AF written and the entire queue unchanged. No retry from entry is a continuation.

Production continuation accepts only `endereco_dependencia=0x420f81`, preserves u16 building/unit/cell metadata and returns at `0x420f8a`, immediately before `SetSortEngin`. The original experience helper saves/restores EDX, so the placement call still consumes the exit cell passed in EBP. It does not rerun healing or conversion. Placement, movement, conditional audio and economic cleanup remain pending; no complete production or real-mission runtime is claimed.

The owner range is a protected modeled allocation, not evidence of the original unchecked behavior for neutral owners.
