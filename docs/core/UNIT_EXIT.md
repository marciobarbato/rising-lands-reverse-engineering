# Physical unit exit and movement order

Stage 8 inventory before implementation, 2026-10-28. Original executable SHA-256 `6c556520c084b9300d9ac01900d1505126085c5f64b1ac5e5b615ea41c8543fb`. End-exclusive original body `SetSortEngin` is `0x445fbc..0x446189`, with shared epilogue `0x4431fb..0x443203`. The production caller slice is `0x420f8a..0x420f9e`.

Public APIs: `colocar_unidade_saida(mundo, indice, celula)` and `retomar_colocacao_saida(mundo, pedido)`. The first takes the existing live physical world, AX index/u16 and DX cell/u16. Protected model inputs require writable 800-record pool, index 0–799, type 0–25, owner 0–3/4/200, local camera 0–3, minimap dimensions 128×128 and a cell within the world's 1–256 dimensions. Invalid protected inputs fail before mutation. This excludes original unchecked invalid state; it does not add an activity filter.

Original mutation order: set destination `+7e`, step `+7c`, current `+8`, and destination `+7e` again; release matching navigation search; clear `+88`; for active states other than 0/4 set state 7 and release matching search again; set u16 `+c0/+b8=ffff`; clear byte `+87` then `+86`. Call `SetEnginCollision` (`0x442cb4`) for the new current cell through existing `ocupar(..., True)`, then set `+72=1`. Prior occupancy is not removed by this body. Matching search release preserves its completion flag.

Owners 4/200 bypass discovery/light. Other owners call existing `descobrir_area(cell, BB+F5+2, owner)` (`0x476851`), then reload live BB/F5 and call `iluminar_area(cell, BB+F5, owner)` (`0x476cb3`). The discovery primitive adds its own one-cell margin. All owners then call `minimapa(owner,cell,4)` (`0x46a388`). These existing physical effects remain single implementations. Initial supported vision sum BB+F5 is 0–8; Stage 14 widened it to 0..`SOMA_VISAO_MAXIMA_INSERCAO` (11), see the [discovery domain](DISCOVERY_DOMAIN.md). Larger vision stops before the discovery call, retaining record/collision/+72 effects. Native comparisons will verify the supported domain and this explicit stop. A physical effect raising an error retains earlier mutations.

`retomar_colocacao_saida` accepts only the experience result at `0x420f8a`. It places that existing unit at the saved exit cell, then reloads the live building u16 `+7c` and invokes committed `definir_movimento` (`0x4457d3`). It returns `ColocacaoSaidaTropa` at `0x420f9e`, before owner comparison/conditional `EnginAsk`. Building index 0–999 and its writable 1,000-record pool are protected before placement. The movement order is not path advancement or arrival. This continuation is one-shot: replay can duplicate discovery/light counts. Neither economy cleanup nor sound is silently skipped; no complete production or mission runtime is claimed.

REA revision `b9a8f8e9f25feb9cc97bf4960748f2bdf8c898bc`, private read-only Ghidra 12.2, normalized PE SHA `26c4534b08b7fdda30c4f5c4b0d665c3f57cd24db3ab3737dd1e0e9c625464d0`, supplied focused `SetSortEngin` and `SetEnginCollision` dossiers. Original register arguments, shared epilogue, jump tables and nested call bytes were inspected separately. Inferred signatures are not authoritative; original native comparisons use the intact oracle. The private session exported and closed before implementation.


Implementation is [colocacao_saida.py](../../ferramentas/colocacao_saida.py), exposed on `MundoFisico`/`MundoNavegacao`. `ColocacaoSaidaTropa(indice, unidade, celula, tipo_unidade, destino_ordem, endereco_dependencia=0x420f9e)` reports the new pending boundary and the requested movement destination. `DependenciaColocacaoSaida` carries unit, original discovery address `0x476851` and caller checkpoint `0x446146`. The preloaded world is the dependency; no separate collision/vision implementation is created.

Before translation, [four original-only captures](../../relatorios/capturas-colocacao-saida-original.json) recorded whole unit-pool hashes, the selected full record, physical-buffer hashes and complete observed collision/discovery/light/minimap call traces. All four match the new Python body without x86. The [initial capture attempt](../../relatorios/colocacao-saida-capture-initial.json) hit the harness cap with an observer reading registers at every instruction. Filtering observation to actual call entries completed all four with unchanged original code/limits.

The first broad [native run](../../relatorios/colocacao-saida-emulada-initial.json) ran 819 segments and had one cap error during the radius matrix; it was not a pass. Replacing the new harness's linear inherited-interval lookup with bisect over the exact declared byte union produced a [successful monolithic run](../../relatorios/colocacao-saida-emulada-monolithic.json): 11 tests, 828 original calls, 666 returns, 156 complete caller checkpoints (52 placement/order plus 104 joined position/conversion/recovery/experience/placement/order), six intentional pre-discovery stops, no buffer differences/faults/skips and maximum 929,654 instructions in one segment. That report predates the final unsaturated-radius test.

An additional [original-only radius-8 diagnostic](../../relatorios/colocacao-saida-radius8-cap.json) with initially empty light counts reached exactly the fixed one-million instruction cap inside minimap work at `0x46a505`. The final validation therefore includes a separate preserved-CPU-state mode: after 50,000 instructions it may stop before actual native `SetMiniMap` entry `0x46a388`, then resume that same instruction with all registers/flags/stack intact. No CALL, RET, original instruction or subcall is replaced; every resume counts as another bounded execution. The per-segment cap and timeout remain unchanged. The ordinary matrix still runs monolithically. Final expanded check passes 12 tests: 846 original entries in 1,038 bounded segments, including 192 such resumptions. Main matrix outcomes are 666 actual returns, 156 caller checkpoints and six pre-discovery stops; all 18 unsaturated-radius entries reach actual returns through the segmented path. Maximum segment instruction counts are 929,654 (ordinary) and 55,454 (segmented). Six Python dependency exceptions intentionally match the six pre-discovery stops. Final failures/errors/native faults/limits/skips are zero; the unsuccessful attempts above remain separate records.

Final local mode discovers 12 tests, executes six and skips six optional native tests, with zero x86. The core domain check passes 314 tests with 149 optional skips. [Final native](../../relatorios/colocacao-saida-emulada.json) and [local](../../relatorios/colocacao-saida-local.json) reports record these results; `demonstrar_colocacao_saida.py` records synthetic exit cell `0x808`, requested destination `0x909`, state 2, enabled byte 1, preserved search completion 77 and old collision retention. It does not advance movement, request sound or clean up production. Reproduce with the exporter/capture/dedicated validator/demonstration scripts and `python3 -B scripts/check.py --domain core`.
