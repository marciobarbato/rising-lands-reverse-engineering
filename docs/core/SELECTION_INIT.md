# Selection list initialization

Stage 9 inventory before implementation, 2026-10-28. Original `SelectionInit` is exactly `0x472555..0x472576` (end exclusive), from intact executable SHA-256 `6c556520c084b9300d9ac01900d1505126085c5f64b1ac5e5b615ea41c8543fb`.

Public API `inicializar_selecoes_unidades(selecoes)` takes a writable bytearray of exactly 2048 bytes, modeled from `0x508728`. It writes four u16 zero words in order at offsets 0, 512, 1024 and 1536, corresponding to original globals `0x508728`, `0x508928`, `0x508b28`, `0x508d28`. It returns None, invokes no callbacks and reads no unit records or list contents. Every other byte remains unchanged, even when counts/contents are inconsistent. Invalid model buffer/length fails before mutation. The model does not infer the rest of each 512-byte list's meaning.

`MundoUnidades.selecoes_unidades` exposes this raw allocation and a matching no-argument method. Constructor zeros are synthetic; mission loading must explicitly call the original initializer at its verified orchestration point. This helper does not clear unit `+bd` flags, deselect units through a UI operation, rebuild lists or claim mission initialization is complete. Missions' `LoadEngin` continuation after `0x46acca` remains separately owned.

Original AX/EDX inputs are unused. Native body saves/restores EDX, XORs it to zero for the ordered stores and returns; full EAX is preserved. Tests compare the whole 2048-byte buffer and entire 800-record unit pool under adversarial inherited contents. The body length is 0x21 (33 decimal) bytes, correcting an earlier chat message that called it 21 bytes. It was inspected directly; no signature inference or POC implementation is required.


Implementation: [selecao_unidades.py](../../ferramentas/selecao_unidades.py). Fresh `validar_selecao_unidades.py --emular` passes five tests and 262 complete original returns: 256 arbitrary list patterns covering every count low byte plus six full-word/selected-flag patterns (0/1/255/256/799/65535). Whole 2048-byte lists and 220800-byte unit pools match; native EAX/EDX preservation also matches. There are no callbacks, dependency stops, native faults, limits, failures, errors or skips. Local mode discovers five tests, executes three and skips two optional x86 tests. Core domain check passes 319 discovered tests with 151 optional skips.
