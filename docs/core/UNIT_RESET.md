# Global unit pool and raw Bag reset

Stage 11 inventory before implementation, 2026-10-28, base `82a0468f5482ef00357bc077a75947c01b44aec4`. Original executable SHA-256 `6c556520c084b9300d9ac01900d1505126085c5f64b1ac5e5b615ea41c8543fb`; complete `EnginResetAll` is `0x441659..0x441775` (end exclusive), 284 bytes with no subcalls.

Missions requested this exact lower prerequisite. Economy confirmed no existing generic raw Bag reset matches it and agreed that core should publish the shared raw primitive; no economic balance/charging behavior is added. Public APIs are `bolsas_inicializacao.resetar_bolsa(memoria, offset=0, *, ordem='tabela')` and `ciclo_unidades.resetar_todas_unidades(mundo)`, with a matching world method.

The raw Bag is 104 bytes. Table-context header-store order is u16 zero at `+0x00,+0x66,+0x04,+0x02`; unit-context order is `+0x66,+0x04,+0x02,+0x00`. For each slot 0–29 in ascending order, write u16 zero at `+0x06+2*slot`, then u8 zero at `+0x42+slot`. All six bytes `+0x60..+0x65` remain unchanged. Capacity/count/entry validity is not tested. The protected Python API accepts writable bytearray or contiguous one-byte B/b memoryview with at least 104 bytes from a nonnegative integer offset, and only the two original order names `tabela`/`unidade`. Malformed inputs fail before stores; no copy/writeback or callback is used.

The world exposes `bolsas_tipos_unidades`: four distinct bytearrays of 26×104=2704 bytes, explicitly modeling the four pointees reached through original global 0x4e19b8. Their physical addresses/contiguity are not invented. Constructor bytes are synthetic; callers may supply inherited buffers and must invoke reset at their verified orchestration point. All pools are validated before effects; bad/aliased model allocations are outside the original unchecked pointer domain.

Original ordered driver: reset all 26 Bags for owner 0, then owners 1/2/3; afterwards scan all 800 unit records in ascending index. A unit with state +2 exactly zero is completely preserved. Every nonzero state, including 4, stores life u16 +0x9a=0, state byte +2=0, experience byte +0xaf=0, then resets its inline Bag at +0x0a in unit header order. No type/owner/life eligibility guard occurs. Every other unit byte and the six Bag reserved bytes remain unchanged.

This routine does not reset selection counts/unit +bd flags, search context, occupancy/regions, discovery/light/minimap, sound handles or group links. It does not allocate/load/insert a unit or tear down old terrain. `SelectionInit`, mission serialization, `Chemin_Remap`, `PlaceEngin` and later orchestration are separate original calls. A zero-filled constructor is not a substitute for these inherited-state semantics.

Original assembly determines the two differing header orders and state predicate; native comparisons will use the intact original. The private session exported and closed before implementation. Whole pools, reserved bytes and native write ordering will be compared, with explicit original-fragment checkpoints for the reusable raw primitive.
